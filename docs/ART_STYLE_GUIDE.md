## 光线、轮廓与材质

- 主光源固定左上。亮面在上、左边缘，暗面在下、右边缘；工作灯可局部照亮，但不得反转体积光。
- 可读主体以 `#10141F` 建立连续 1px 外轮廓；相邻内部深缝可复用此色。仅在与煤黑背景贴合时可断开内侧轮廓。
- 金属使用“暗面 → 中间调 → 1px 高光”的硬阶；岩石用 2～3 块不规则面和短裂缝；晶体是硬边菱形，亮面最多 1～2 像素；蒸汽使用离散团块，不透明、不柔化；发光材质以浅色核心和邻接亮块表达，不使用透明晕染。
- 每个 16px 资源先完成轮廓与 2～4 个大材质簇，再加入最多 3 个功能性细节（铆钉、裂纹、读数、警示）。禁止以均匀散点或随机噪点伪装细节；状态变化必须优先改变姿态、开口、轮廓或可见能量路径。
- 场景按“近景遮挡 → 可行走中景 → 远景机器/岩层 → 深背景”分层。暖灯只标出路径、工作台和交互物，不平均照亮画面；矿物、危险、轨道和支撑组成可读的路线节奏，而不是平铺陈列。
- **黄金样板锁定方向（2026-08）**：采用明确的横版纯 2D 侧视构图，不使用斜投影、伪透视地板或会被误读成 2.5D 的倾斜结构。深背景以 `#10141F/#1B2638` 为主，远景设施仅使用低对比蓝钢色；中景钢架和铜管形成路线；前景的碰撞岩层、矿物和危险使用完整轮廓与最高对比。全局冷蓝工业底色只由少量 `#F0D77A` 工作灯切开。
- HUD 固定为底部独立仪表轨：画面底部保留 28 逻辑像素，外框与场景分离。每组状态由“16px 轮廓图标 → 间隔 → 独立黑色读数槽 → 实色状态条”组成；组与组之间至少保留 8px 或使用分隔线。HUD 不得借用场景灯光、管线或地形纹理作边框。

## 钻机与动画

默认层序从后到前：货运框架 → 紧凑推进器 → 32×32 主体 → 铜环散热器 → 遥控爆破钉 → 硬质合金齿 / 钻探粒子。所有钻机帧中心锚点为 `(16,16)`。

默认钻机主形象锁定为“矮壮维修爬行机”：下部为短履带/承重底盘，中部为铜色维修锅炉与蓝钢观察窗，前部为窄而明亮的硬质合金钻齿，后部保留紧凑推进器。细节必须强化这一轮廓，不能改造成悬浮飞船或细长车辆。

| 状态 | 帧数 | 播放 |
|---|---:|---:|
| 待机、推进、过热 | 4 | 10 fps |
| 钻探 | 6 | 10 fps |
| 轻度、重度损伤 | 各 1 | 静态 |
| 损毁 | 8 | 10 fps，一次播放 |
| 矿物、危险、生物 | 见元数据 | 8 fps |

## 命名、画布与导入

- 文件名：小写 snake_case；精灵表在 `assets/sprites/`，源矩阵在 `assets/art_source/`，预览在 `assets/previews/`。
- 主体与模块为 32×32；工业瓦片、矿物、危险、虫与 UI 图标为 16×16；维修工坊 L1 为 48×32。锚点一律见 manifest；瓦片锚点 `(8,8)`。
- Godot 导入：关闭过滤、关闭 mipmap、保持原始尺寸；TextureFilter 选择 Nearest，所有位置和缩放为整数，使用 `Centered` 与 manifest 中的锚点。
- UI 使用 8px 间距。九宫格边界保持 4px，不缩放边缘像素；16px 图标在 1× 下必须靠轮廓和形状区分，不能只靠颜色。

## 禁止事项

禁止柔化、抗锯齿、插值、渐变污染、半透明脏边、半像素位置、未登记颜色、直接修改生成 PNG，以及以纯颜色变化作为唯一交互提示。
